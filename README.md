# Hive Break — Website

Static marketing site for hivebreak.com. No build step.

- `index.html` — page markup
- `styles.css` — design system & layout
- `app.js` — honeycomb canvas, scroll reveals, counters
- `assets/` — logo, favicon, founder photo

Local preview: open `index.html`, or run `python3 -m http.server 8000`.
